================================================================================
               HOW TO RUN THE BULK CERTIFICATE GENERATOR
================================================================================

This project includes both:
1. BACKEND: A FastAPI Python server with background parallel PDF generation.
2. FRONTEND: A modern, interactive web dashboard served directly at http://localhost:8000


--------------------------------------------------------------------------------
STEP 1: OPEN YOUR TERMINAL
--------------------------------------------------------------------------------
Make sure your terminal is inside the project directory:
   cd /home/lanson/Music/assignment


--------------------------------------------------------------------------------
STEP 2: ACTIVATE THE VIRTUAL ENVIRONMENT
--------------------------------------------------------------------------------
Run this command in your terminal:

On Linux / macOS:
   source venv/bin/activate

On Windows:
   venv\Scripts\activate

(You will see "(venv)" appear at the start of your terminal prompt line.)


--------------------------------------------------------------------------------
STEP 3: INSTALL DEPENDENCIES (Already installed, but if needed)
--------------------------------------------------------------------------------
   pip install -r requirements.txt


--------------------------------------------------------------------------------
STEP 4: START THE APPLICATION (Both Backend & Frontend)
--------------------------------------------------------------------------------
Run this single command:

   uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

You will see:
   INFO: Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
   INFO: Application startup complete.


--------------------------------------------------------------------------------
STEP 5: OPEN THE FRONTEND IN YOUR BROWSER
--------------------------------------------------------------------------------
Open Google Chrome, Firefox, or any web browser and go to:

   http://localhost:8000   (or http://127.0.0.1:8000)

That's it! The full interactive web dashboard will open.


--------------------------------------------------------------------------------
HOW TO USE THE WEB DASHBOARD
--------------------------------------------------------------------------------

Option A: Quick 1-Click Demo (Easiest way to test)
1. In the "Upload CSV File" tab, click the button:
   "Load Demo Data (3 Recipients)"
   (This pre-loads: Lanson Bardeskar, Saurav Swami, Kanif Kumbhar)
2. Click the big purple button: "Generate 3 Certificates"
3. Watch the live progress bar reach 100%!
4. Click "Download PDF" next to any name to view or save the generated certificate.

Option B: Using a CSV File
1. Click "Download Sample CSV" to get a pre-formatted template file.
2. Drag and drop your CSV file into the upload box (or click to browse).
3. Check the parsed preview table.
4. Click "Generate Certificates".

Option C: Manual Entry
1. Click the "Manual / Paste Entry" tab.
2. Click "Fill Sample" (or type any name and email in "Name, email" format).
3. Click "Generate Certificates".


--------------------------------------------------------------------------------
ADDITIONAL FEATURES
--------------------------------------------------------------------------------

1. SWAGGER API DOCUMENTATION (Interactive API Testing):
   Go to: http://localhost:8000/docs
   Here you can test all backend endpoints (POST /api/jobs, GET /api/jobs, etc.) directly.

2. RUN AUTOMATED TESTS:
   In your terminal (with venv activated), run:
      pytest -v
   All 49 unit and integration tests will run and pass!

   To see test coverage (96%):
      pytest --cov=app --cov-report=term-missing -v

3. TO STOP THE SERVER:
   In the terminal where uvicorn is running, press:
      CTRL + C
